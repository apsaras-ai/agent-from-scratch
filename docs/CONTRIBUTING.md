# 贡献指南

欢迎通过 Issue 讨论技术问题、章节结构和实验复现，通过 Pull Request 提交勘误、原创教程、练习及代码改进。

1. 先阅读 [教材目录](../book/README.md)。
2. 每个技术主张尽量引用原论文、官方文档或可复现实验。
3. 每章尽量按 Why → Theory → Design → Implementation → Evaluation → Research 编写。
4. 示例代码需有运行说明及自动化测试；严禁把真实 API Key 提交进仓库。
5. 不要复制受版权保护的课程讲义、论文全文或第三方代码。

目前尚未设定正式开源许可；提交第三方内容前请先确认版权与再许可条件。
